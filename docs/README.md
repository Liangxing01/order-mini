## 写作约定

每篇文档固定包含以下几节，按需增减：

1. **功能是什么** —— 一句话说清用户能看到什么。
2. **规则与边界** —— 权限矩阵、限制（次数、数量、唯一性）。
3. **数据结构** —— 新增/变更的集合与字段。
4. **接口** —— 云函数 action、入参、出参、错误码。
5. **前端交互** —— 页面、入口、状态流转。
6. **兼容与迁移** —— 历史数据怎么办。
7. **验证清单** —— 上线前手动点一遍的步骤。

## 术语

- **平台角色**：`user.role`，取值 `supervip` / `vip` / `user`。
- **家庭角色**：`user.familyRole`，取值 `owner`（房主）/ `member`（成员）。
- **家庭**：`family` 集合里的一个文档，一个账号同一时间只属于一个家庭。
